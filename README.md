# DOGFIGHT — Sito web

Sito vetrina per **DOGFIGHT**, azienda ipotetica di difesa aerea italiana fondata da Giacomo Larizza, realizzato a partire dal documento di Corporate Identity.

**Sezioni:** Chi siamo · La nostra storia · Il nostro volto (identità visiva) · I nostri obiettivi · Our Vision · LAZZAR-1 (Our Mission) · Shop · Contatti

## Tecnologie
- HTML, CSS e JavaScript, senza build
- [GSAP](https://gsap.com/) + ScrollTrigger per le animazioni
- [Lenis](https://lenis.darkroom.engineering/) per lo scroll fluido
- Logo vettoriale originale estratto dal PDF

## Aprirlo in locale
Apri `index.html` nel browser, oppure avvia un server statico nella cartella:

```
python -m http.server 8417
```

*Progetto a scopo didattico — azienda ipotetica.*
